# Security

If you believe you have found a security problem in Penqwin ERP, please write to [hello@penqw.in](mailto:hello@penqw.in) with the subject "Security" and the details needed to reproduce it. Please do not post it publicly until it has been looked at.

Download the installer only from this repository's releases or from [penqw.in](https://penqw.in), and check it against the SHA-256 published with the release (see [docs/INSTALL.md](docs/INSTALL.md)).
